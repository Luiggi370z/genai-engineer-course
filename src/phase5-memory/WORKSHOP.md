# Workshop · Memory and crew

Workshops 2–8 are one assistant. This phase is one folder of it.

Read [How to work with workshops](../workshops/README.md) first.

1. Open `src/workshops/assistant/phases/05-memory/before`.
2. Edit `src/assistant/memory.py`, `src/assistant/tenancy.py`, and `src/assistant/crew.py`.
3. Read the brief: [`WORKSHOP-MEMORY-CREW.md`](../workshops/assistant/phases/05-memory/WORKSHOP-MEMORY-CREW.md).
4. Run `make setup`, then `make test`. The first failure is `test_a_remembered_fact_comes_back_with_its_source`.
5. When `make test` is green, or you are stuck, diff those files against the same paths under `../after`.
