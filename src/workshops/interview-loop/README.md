# Workshop 9 · The interview loop

The last workshop, and the only one with no code. Workshops 1–8 built the system;
this one builds the loop that turns it into offers — and keeps you current after the
course stops updating.

There is no `before/` or `after/` here, because there is nothing to make pass. The
artifacts are yours: a schedule you actually follow, recordings of yourself, and a
funnel with real numbers in it.

Brief: [`WORKSHOP-INTERVIEW-LOOP.md`](WORKSHOP-INTERVIEW-LOOP.md).

| File | Use it for |
|------|-----------|
| [`WORKSHOP-INTERVIEW-LOOP.md`](WORKSHOP-INTERVIEW-LOOP.md) | The brief: what you build, and the deliverables that say you're done |
| [`DESIGN-MOCK-RUBRIC.md`](DESIGN-MOCK-RUBRIC.md) | Score a recorded design mock against the Phase 4 script — 8 rows, honestly |
| [`METRICS-WORKSHEET.md`](METRICS-WORKSHEET.md) | Mine the numbers out of Workshops 1–8, and track the search funnel |

```bash
# The only "run" command this workshop has
cp METRICS-WORKSHEET.md ~/job-search/metrics.md
cp DESIGN-MOCK-RUBRIC.md ~/job-search/mock-01.md
```

Copy them somewhere you will see them daily. A rubric you fill in once is a
document; a rubric you fill in eight times is a training signal.
