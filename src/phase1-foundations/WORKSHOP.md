# Workshop · The model bench

This phase's workshop is its own project. It does not grow into the assistant.

Read [How to work with workshops](../workshops/README.md) first.

1. Open `src/workshops/model-bench/before`.
2. Read the brief: [`WORKSHOP-MODEL-BENCH.md`](../workshops/model-bench/WORKSHOP-MODEL-BENCH.md).
3. Run `make setup`, then `make test`.
4. When the tests are green, or you are stuck, diff your files against `../after`.
