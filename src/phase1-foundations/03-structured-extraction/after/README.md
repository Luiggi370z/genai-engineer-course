# 1.3 Structured extraction — reference

Typed `Invoice` via Instructor; same code hosted or local. The client is injected, so
the offline tests exercise the real extraction path against a fake — including
`compare_providers`, which reports both numbers the shoot-out needs: `violation_rate`
(which constrained decoding drives to ~0 for everyone, so it decides nothing) and
`field_accuracy` per field, which is where the laptop model loses on `date`.
